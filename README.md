# HTML Tags Learning Project

A simple project created to practice and learn basic HTML tags and webpage structure using HTML and CSS.

## 🚀 Technologies Used

* HTML5
* CSS3

## 📚 About the Project

This project is made for learning and practicing:

* Basic HTML tags
* Headings and paragraphs
* Images and links
* Lists and tables
* Forms
* Page structure
* Basic CSS styling

## 🎯 Purpose

The main goal of this project is to improve understanding of HTML and CSS fundamentals through practical implementation.

## 📂 Features

* Simple and clean UI
* Beginner-friendly structure
* Practice of important HTML tags
* Basic responsive design

## 🛠️ How to Run

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser
